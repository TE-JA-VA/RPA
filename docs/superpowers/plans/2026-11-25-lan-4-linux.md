# 사내 서버 ④ 리눅스에 싣기 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사내 서버를 리눅스 서버에 설치 파일 하나로 깔아 systemd 서비스로 돌린다 - 내장 파이썬, 서버 입구와 관리 명령(`autopilot-server`), 서버 라이선스와 자리 증명서, 폴더 권한, 기록 파일, 백업과 복구, `install.sh`, 그리고 NT 첫 설치.

**Architecture:** 서버 코드는 ①~③ 의 `local_server`·`local_web`·`lan_*` 그대로이고, 리눅스에서 켜는 입구 `server_main.py` 가 경로(`/etc`·`/var/lib`·`/var/log/autopilot`)와 라이선스·인증서·등록부를 모아 `lan_server.make_lan_servers` 로 두 포트를 연다. 윈도우 전용 자리(`icacls`, 창 없는 깃발, 주소 다시 쓰기)는 `os.name` 으로 가른다. 설치 파일은 `tools/build_server.py` 가 내장 파이썬(python-build-standalone)과 서버 파일, 웹 파일, 서명된 버전 목록, `install.sh`, systemd 단위로 묶는다. 휴대폰 포트(8782)는 ⑧ 에서 연다 - 이번에는 열지 않는다.

**Tech Stack:** 파이썬 3.14 표준 라이브러리, POSIX sh(`install.sh`), systemd, openssl 명령(서버의 것), 시험은 plain python + WSL(Ubuntu, Python 3.14.4, OpenSSL 3.5.5) + NT(Ubuntu 24.04.5, Python 3.12.3, OpenSSL 3.0.13 - 서버는 내장 파이썬으로 돈다).

**Spec:** `docs/superpowers/specs/2026-11-24-standalone-linux-server-design.md` 4.3, 6.2, 6.3 (방화벽·인증서 ①②), 6.8, 8절 ①②, 9절, 10절 NT 줄, 13절 9, 14절 ④. 목록 `docs/superpowers/plans/2026-11-24-lan-index.md` 에서 ④ 로 넘긴 것: M-8, 보류 1, ②-T2, ②-T8, ②검-3·4·5·6·7·9·10, ②보-1·2, ③-1, ③검-1·8·9, ③보-1·2.

## Global Constraints

- 작업 폴더 `D:\AX\RPA_StandAlone`, 브랜치 `StandAlone`. 파이썬 `D:\AX\RPA\.venv\Scripts\python.exe`, cwd 작업 폴더, `$env:PYTHONUTF8="1"`. `D:\AX\RPA` 의 파일은 절대 고치지 않는다 (PowerShell 에서 .NET 메서드에 상대 경로 금지 - 그 폴더로 풀린다).

- 경로 (설계 6.2): 프로그램 `/opt/autopilot/releases/<버전>/` + 링크 `/opt/autopilot/current` (root, 서비스는 읽기만), 설정 `/etc/autopilot/` (`server.json`, `license.json` - 서비스 읽기만, `ca/` 인증 기관 열쇠 - root 만 700), 자료 `/var/lib/autopilot/` (서비스 계정 `autopilot` 만, 폴더 700·파일 600), 기록 `/var/log/autopilot/` (`server.log`, `audit.log`, 10MB 다섯 개).

- 기록·응답에 열쇠, 비밀번호, 세션 토큰, 인증번호, 2단계 비밀 값, 자리 서명 열쇠를 싣지 않는다.

- 화면·기록 글은 한국어 업무 말투 ('버전', '페어링', '묶음' 금지). 리눅스 관리자용 파일 이름과 명령은 영문.
