# 옵저버 단독 버전 - 설계

2026-11-03 사용자 요청. 이 문서는 설계만 다룬다. 구현 계획은 이 문서가 승인된 뒤 따로 쓴다.

## 1. 무엇을, 왜

오토파일럿 가운데 **옵저버(기록) + ACTOR(프리셋 재생)** 만 떼어 ERPia 없이 쓰는 설치 파일을 만든다.
사내에서 쓴다. 사람이 옵저버로 사이트 작업을 기록해 프리셋으로 저장하고, 그 프리셋을 정한 요일·시각에 자동으로,
또는 아무 때나 손으로 돌린다. 제어는 그 PC 에서만 여는 로컬 관제 화면에서 한다.

## 2. 목표 / 하지 않을 것 / 실패로 볼 것

목표
- 옵저버 단독 설치 파일 (오토파일럿과 따로 설치).
- 예약: 요일·시각 + **돌릴 프리셋 지정**. 반복(시간대)·휴무일은 지금 예약기에 있는 그대로 쓴다.
- 수동 실행: 프리셋을 골라 [지금 실행].
- 로컬 관제 화면 (오토파일럿 홈 디자인 차용, 웹에 올리지 않음).

하지 않을 것 (사용자 2026-11-03)
- ERPia 관련 전부: PROCESS(루틴), 엑셀 업로드, 함께 실행, 모듈 고르기.
- 에이전트·Firebase 연결: 토큰(제한 없이 돈다), 휴대폰 인증번호 중계, 업체 웹 화면, 관리 화면, 원격 명령.
- 자동 업데이트 - 새 버전은 설치 파일로만.
- 다른 PC·휴대폰에서 관제 화면 열기, 로그인·계정.

실패로 볼 것
- 단독 버전 때문에 오토파일럿 쪽 동작이 바뀌는 것 (공용 코드는 같은 결과여야 한다).
- 오토파일럿과 단독 버전을 한 PC 에 깔았을 때 서로의 프리셋·설정·기록·포트를 건드리는 것.
- 관제 화면이 이 PC 밖에서 열리는 것.

## 3. 정해진 것 (사용자)

| 항목 | 결정 |
|---|---|
| 토큰 | 제한 없이 돈다 |
| 2차인증 | 사람이 한다 (4.4) |
| 업데이트 | 설치 파일로만 |
| 쓰는 곳 | 사내 |
| 관제 화면 | 그 PC 에서만, 단독 옵저버만 제어 |

## 4. 어떻게 (Claude 판단 - 사용자 확인 대상)

### 4.1 저장소
같은 저장소·같은 develop. 빌드가 설치 파일을 둘 낸다 (`AUTOPILOT_Setup_<버전>.exe`, `Observer_StandAlone_Setup_<버전>.exe`).
까닭: 옵저버·재생·메일 2차인증·예약기가 공용이라 떼면 고침을 두 곳에 옮겨야 한다.
단독 전용 코드는 새 파일로 두고, 공용 코드에는 '단독인가' 한 가지 표시만 본다.

### 4.2 구성
설치 폴더에 들어가는 것
- `Prepare_Observer.exe` - 지금 옵저버 그대로 (ERPia 칸·휴대폰 칸은 단독이면 숨김, 4.5).
- `Prepare_RPA.exe` - 지금 ACTOR 그대로 (함께 실행·루틴 띄우기는 단독이면 하지 않음).
- `Observer_Hub.exe` (새) - 로컬 서버 + 예약기. 지금 `rpa_dashboard.py` 의 예약기(`Scheduler`, 슬롯 계산, 휴무일, 절전 깨우기)와
  띄우기(`launch`)를 그대로 쓰고, 화면·API 만 단독용으로 새로 둔다.
- 관제 화면 html/js/css (새) - `Observer_Hub` 가 내보낸다.

넣지 않는 것: `ERPia_RPA.exe`, 에이전트(node·agent), 업데이트 도우미, ERPia 설정 창.
설치 마법사는 ERPia 위치·에이전트 계정을 묻지 않는다.

### 4.3 관제 화면과 로컬 서버
- `Observer_Hub` 는 **127.0.0.1 에만** 연다 (다른 PC 에서 못 연다). 로그인 없음.
  다른 웹 페이지가 이 서버를 부르지 못하게 쓰기 요청은 Host·Origin 을 검사한다 (관리 화면 AFTERMARKET_SETUP 과 같은 방식).
- 포트는 오토파일럿(8765)과 다른 번호 (8775 안, 이미 쓰고 있으면 비어 있는 다음 번호).
- 설치하면 바탕화면·시작 메뉴에 '옵저버 관제' 바로가기 (브라우저로 그 주소를 연다). `Observer_Hub` 는 윈도우 시작 때 뜬다.
- 화면 (오토파일럿 홈 디자인 차용 - 색·카드·표·상태 알약)
  1. 현황: 지금 도는 프리셋·단계, 사람 입력을 기다리는 중이면 크게 알림 (4.4), [중지].
  2. 프리셋: 목록 (번호·이름·사이트코드·켬/끔·마지막 결과), 고르고 [지금 실행], [옵저버 열기].
  3. 예약: 줄마다 요일·시각(또는 시간대 반복)·**돌릴 프리셋** (모두 / 고른 것). 공휴일·휴무일 쉬기.
  4. 기록: 실행 기록 표 (언제·어느 프리셋·결과·받은 파일 수), 실패 화면 사진 열기.
  5. 설정: 받은 파일 폴더, 동시 실행 창 수.

### 4.4 2차인증은 사람이
- 문자 인증번호 단계 (`otp`, 휴대폰 중계 없음): [인증번호 받기]까지는 기록대로 재생기가 누른다. 그 뒤 인증번호 칸에서 멈추고
  브라우저 창을 앞으로 띄운 채 **사람이 번호를 넣고 [확인]까지** 누르기를 기다린다. 재생기는 번호 채우기와 기록된 [확인] 단계를
  건너뛰고, 인증번호 칸이 사라지거나 주소가 바뀌면(지금 `_otp_rejected` 의 '넘어감' 판정과 같은 기준) 그 다음 단계부터 이어 간다.
- 틀린 번호·재발송은 사람이 그 화면에서 직접 한다. 재생기는 다시 보내지 않는다 (지금의 3회 다시 시도는 쓰지 않음).
- 기다림은 그 인증 한 번에 **5분** (사용자 2026-11-03). 넘으면 그 프리셋만 실패.
  기다리는 동안 관제 화면에 '인증번호 입력 대기 - 프리셋 N' 을 보인다.
- 오토파일럿의 재생은 바뀌지 않는다 - 사람 대기는 단독 버전이 휴대폰 중계 대신 꽂는 것으로만 들어간다.
- 기록에 없던 2차인증 화면이 나오는 것은 지금처럼 실패.
- 메일 2차인증(옵저버로 메일함까지 기록한 것)은 PC 안에서 혼자 되므로 지금처럼 자동.
- 사람이 넣어야 하는 프리셋은 예약 실행 때 사람이 PC 앞에 있어야 한다 - 화면에 그 프리셋에 '사람 입력 필요' 표시.

### 4.5 옵저버 저장 화면
- 단독이면 휴대폰(인증 휴대폰·발신번호) 칸을 숨기고, 인증번호 단계가 있어도 휴대폰을 요구하지 않는다.
- 사이트코드(세 자리)는 지금처럼 받는다 - 받은 파일 이름 앞 `(코드)` 와 같은 사이트 짝 확인에 쓴다.

### 4.6 데이터·공존
- 단독 버전은 설치 폴더·데이터 폴더(프리셋·설정·기록·세션·메일 기억)를 오토파일럿과 따로 쓴다
  (`ProgramData\...\Observer` 아래). 같은 PC 에 둘 다 깔려도 서로 안 본다.
- 옵저버 잠금·실행 중 잠금도 단독 쪽 이름으로 - 오토파일럿 옵저버가 떠 있어도 단독 예약은 막히지 않는다.
- 단독 옵저버가 떠 있는 동안 온 예약은 지금 예약기처럼 옵저버가 닫힐 때까지 미룬다 (그 사이 지난 예약은 한 번으로 합친다).
  [지금 실행]은 '옵저버가 실행 중입니다' 로 막는다 (지금과 같다).

### 4.6a 권한·시작
- 오토파일럿과 같다: 설치할 때 작업 스케줄러에 '로그온 시, 그 사용자, 대화형, 가장 높은 권한' 으로 `Observer_Hub` 를 등록한다
  (`rpa_settings.task_xml` 과 같은 모양). 옵저버·ACTOR 는 Hub 가 같은 사용자·권한으로 띄운다 - 잠긴 비밀번호(DPAPI)를 같이 푼다.
- 예약은 그 사용자가 로그인해 있을 때만 돈다 (오토파일럿과 같은 가정). 로그오프 상태 실행은 하지 않는다.
  ponytail: 둘이 동시에 Edge 를 띄우면 화면이 겹칠 수 있다 - 실제로 같이 쓰는 PC 가 생기면 그때 막는다.

### 4.7 받은 파일
- 받은 파일 폴더는 사용자가 관제 화면 설정에서 정한다 (기본 `바탕화면\AI`, 사용자 2026-11-03). 이름은 지금처럼 `(사이트코드)원래이름`.
- 단독에는 가져가는 쪽(ERPia 업로드)이 없으므로 파일은 쌓인다. 지우지 않는다.

### 4.8 빌드·시험
- `tools/build_release.py` 가 같은 버전 번호로 단독 설치 파일도 만든다 (exe 는 같은 빌드 결과를 나눠 담는다).
- 샌드박스 시험에 단독 설치 → 관제 화면 열림 → 예약 저장 → 수동 실행(가짜 사이트) → 제거 를 더한다.
- 공용 코드 시험은 지금 것 그대로 통과해야 한다. 단독 표시를 켠 경우의 시험을 더한다.

## 5. 남긴 것 (구현하며 정함)
- 관제 화면의 세부 배치·문구 (docs/ui-wording.md 업무 서식 말투).
- `Observer_Hub` 가 `rpa_dashboard.py` 의 예약기를 가져다 쓰는 방식 (모듈 import 또는 공용 부분 분리).
- 단독 표시를 무엇으로 알지 (설치 폴더의 표시 파일 등).

## 6. 확인한 것 (사용자 2026-11-03)
- 받은 파일 폴더는 사용자가 정한다, 기본 `바탕화면\AI`.
- 사람 입력 대기 5분 (2차인증은 아마 없을 것).
