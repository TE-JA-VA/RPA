# 화면·기록 글 기준 (업무 서식)

2026-10-16 확정. 업체 직원·관리자가 보는 글(화면, 알림, 확인 창, 실행 기록, 실패 사유)은 아래 기준으로 씁니다.
업체 직원용 사용 설명서만 "~해 주세요" 존댓말을 그대로 씁니다.

## 끝맺음

| 쓰임 | 쓰는 꼴 | 예 |
|---|---|---|
| 알림·결과 | ~합니다 / ~하였습니다 | 설정을 저장하였습니다. |
| 부탁 | ~하여 주십시오 | ERPia 아이디를 입력하여 주십시오. |
| 묻기 | ~하시겠습니까? | 계정을 사용중지하시겠습니까? |
| 진행 중 | ~하는 중입니다 | 파일 다운로드를 기다리는 중입니다. |
| 이름표·상태 | 명사형 (마침표 없음) | 실행 중, 꺼짐, 대상 없음 |

- 문장은 마침표로 끝냅니다. 괄호는 마침표 뒤에 둡니다: `저장하지 못했습니다. (오류 내용)`
- `A - B` 처럼 줄표로 잇지 않고 두 문장으로 나눕니다: `실행할 수 없습니다. 다시 시도하여 주십시오.`
- 화살표(`->`)로 잇지 않습니다: `폴더가 없어 엑셀업로드를 건너뜁니다.`
- 조사는 붙여 씁니다: `PC가`, `ERPia를`, `옵저버에서`

## 낱말

| 쓰지 않는 말 | 쓰는 말 |
|---|---|
| 넣다 | 입력, 등록 |
| 고르다 | 선택 |
| 빼다, 지우다 | 삭제 |
| 끄다, 끊기다 | 종료 |
| 켜다 (프로그램) | 실행 |
| 멈추다 | 중단 |
| 돌다, 돌고 있다 | 실행 중 |
| 받다 (파일) | 다운로드 |
| 받다 (문자) | 수신 |
| 보내다 | 전송 |
| 바꾸다 | 변경 |
| 만들다 | 생성, 등록 |
| 잘못되었습니다 | 올바르지 않습니다 |
| 맞지 않습니다 (비밀번호) | 일치하지 않습니다 |
| 두 번 있습니다 | 중복되어 있습니다 |
| 뜻밖의 오류 | 예기치 않은 오류 |
| 판 | 버전 |
| 쉬다, 쉬는 날 | 휴무, 휴무일 |

사용자가 고른 말: **공휴일 휴무 적용**, **휴무일**, "수동 실행으로 진행할 수 있습니다", "자동 실행 슬롯은 최대 N개까지입니다. 추가를 원하시면 ERPia에 문의해주세요.", "이미 최신 업데이트를 사용하고 있습니다", "현재 접속한 업체는 사용할 수 없는 모듈입니다."

## 바꾸면 안 되는 글 (코드가 글자로 알아본다)

글을 바꾸기 전에 저장소 전체에서 그 글자를 찾아, 비교(`in`, `includes`, `==`, 정규식)에 쓰이면 그대로 둡니다.

- `대시보드에서 중단했습니다` (STOPPED_TEXT - PC와 웹이 같이 봄, 옛 PC도 보냄)
- `토큰이 없습니다` 로 시작하는 글 (웹이 정규식으로 봄)
- `화면이 잠겨` (웰라이프 LOCKED_TEXT - 예약기가 봄)
- `대상 없음`, `화면에 없음` (단계 상태 이름)
- `문제:` 로 시작하는 점검 줄, `쓸 수 있는 Action`, `옵저버 점검 끝` (빌드·샌드박스가 봄)
- ERPia가 띄우는 글 (배송일을 지정하세요 등 필수값 안내, 새로 생성한 배송장을 우선 조회하였습니다, 열 수 없습니다·찾을 수 없습니다·존재하지 않습니다, 개체 참조가 개체의 인스턴스로 설정되지 않았습니다)
- `이미 등록된 계정입니다` (ops.setupCompany 가 '건너뜀' 을 가릴 때 봄)

## 적용 범위 (2026-10-16)

바꿈: 업체 웹, 오토파일럿 설정 창, 관리 화면·관리 작업, 옵저버·ACTOR 기록, 예약·에이전트·업데이트 결과 글, PROCESS 기록(ERPia 글 제외).
남김: 웰라이프 기록(`wellife.py` - 담당자가 이 기준으로 맞춤), 옛 로컬 대시보드(8765)·개발자 명령줄 도움말·코드 주석.
