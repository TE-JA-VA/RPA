# 오토파일럿 사용 설명서

## 요약

오토파일럿은 ERPia 업무(주문 처리, 물류, 운송장 등)를 대신 눌러 주는 프로그램입니다.
처음 한 번만 설정해 두시면, 정해 둔 시각에 알아서 실행됩니다.

1. **설치**: 설치 파일을 열고 [예] → [설치] 를 누릅니다.
2. **처음 설정**: 자동으로 뜨는 '오토파일럿 설정' 창에 받은 정보를 넣고 [저장] 을 누릅니다.
3. **로그인**: 시작 메뉴의 '오토파일럿 대시보드' 를 열고 로그인합니다.
4. **실행할 일 정하기** (관리자): [환경설정] 에서 실행할 일과 시각을 고르고 [적용] 을 누릅니다.
5. **결과 보기**: [오토파일럿] 화면에서 결과를 확인하시면 됩니다. 업데이트는 자동으로 됩니다.

**꼭 지켜 주세요**
- 실행 시각에는 PC 가 켜져 있고, 윈도우에 로그인되어 있어야 합니다.
- 실행되는 동안에는 그 PC 의 마우스와 키보드를 만지지 말아 주세요.

---

## 준비해 주실 것

담당자가 미리 전해 드립니다. 없으시면 담당자에게 요청해 주세요.

| 무엇 | 어디에 씁니까 |
|---|---|
| 설치 파일 (AUTOPILOT_Setup_….exe) | 1. 설치 |
| 업체코드, PC코드, 에이전트 계정 비밀번호 | 2. 처음 설정 |
| 대시보드 아이디, 비밀번호 | 3. 로그인 |

ERPia 업체코드, 아이디, 비밀번호는 평소 ERPia 에 로그인하실 때 쓰시는 것입니다.

---

## 1. 설치하기

1. 설치 파일을 두 번 누릅니다.
2. 'Windows의 PC 보호' 창이 뜨면 [추가 정보] → [실행] 을 누릅니다.
3. "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 가 뜨면 [예] 를 누릅니다.
4. [설치] 를 누릅니다.
5. 설치가 끝날 무렵 '오토파일럿 설정' 창이 자동으로 뜹니다. 다음 2번으로 넘어가 주세요.

> "옵저버가 켜져 있습니다" 또는 "오토파일럿이 돌고 있습니다" 가 나오면, 끝날 때까지 기다리거나 창을 닫은 뒤 다시 설치해 주세요.

## 2. 처음 설정하기 ('오토파일럿 설정' 창)

창이 보이지 않으면 **시작 메뉴 → 오토파일럿 → 오토파일럿 설정** 을 눌러 여실 수 있습니다.

1. **대시보드 연결**: 담당자에게 받은 업체코드, PC코드, 에이전트 계정 비밀번호를 넣습니다.
2. **ERPia 로그인**: ERPia 업체코드, 아이디, 비밀번호를 넣습니다.
   - 'ERPia 설치 위치' 는 비워 두셔도 됩니다. 알아서 찾습니다.
3. **물류 처리 옵션**: 택배사, 박스, 운임을 넣습니다.
   - ERPia 의 배송정보설정에 적힌 글자와 **똑같이** 넣어 주세요. 다르면 물류관리에서 저장되지 않습니다.
   - 출력 방식은 처음 그대로 '수동 - 엑셀 파일' 로 두시면 됩니다. 운송장을 바로 인쇄하려면 '자동 - 운송장 인쇄' 와 프린터를 고릅니다.
4. 아래의 [저장] 을 누릅니다.
5. 잠시 뒤 "설정을 마쳤습니다" 가 나오면 끝입니다. [닫기] 를 누르셔도 됩니다.

> 빨간 글씨가 나오면 그 칸을 다시 확인해 주세요. (예: "ERPia 아이디를 넣으세요")
> 비밀번호 칸에 "저장됨 - 바꿀 때만 입력" 이 흐리게 보이면, 바꿀 때만 새로 넣으시면 됩니다.

이후로는 윈도우에 로그인할 때마다 오토파일럿이 창 없이 저절로 켜집니다. 따로 켜실 필요는 없습니다.

## 3. 대시보드 로그인

어느 PC, 어느 휴대폰에서든 인터넷 창으로 결과를 보실 수 있습니다.

1. **시작 메뉴 → 오토파일럿 → 오토파일럿 대시보드** 를 누릅니다.
   (다른 기기에서는 https://rpa-test-f02e0.web.app 로 들어갑니다.)
2. 업체코드, 아이디, 비밀번호를 넣고 [로그인] 을 누릅니다.
   - '업체코드·아이디 저장' 에 체크해 두시면 다음부터 비밀번호만 넣으시면 됩니다.

> "업체코드, 아이디 또는 비밀번호가 맞지 않습니다" 가 나오면 담당자에게 확인해 주세요.

## 4. 결과 보기 ([오토파일럿] 화면)

왼쪽 메뉴의 **오토파일럿** 을 누릅니다. PC 가 여러 대이면 제목 옆에서 PC 를 고릅니다.

- **현황** 탭: 지금 상태(진행 중, 성공, 실패 등), 처리한 주문 수, 다음 자동 실행 시각을 보여 드립니다.
  - '연결' 이 **정상** 이면 PC 와 잘 이어져 있는 것입니다.
- **기록** 탭: 날짜를 고르면 그날 언제 무엇을 실행했고 결과가 어땠는지 표로 보여 드립니다.

## 5. 지금 바로 실행하기 (관리자)

[오토파일럿] 화면 오른쪽 **실행** 칸에서 누릅니다.

| 단추 | 하는 일 |
|---|---|
| [전체 실행] | 쇼핑몰 주문 받기부터 ERPia 처리까지 모두 |
| [ACTOR 오토파일럿] | 쇼핑몰에서 주문 엑셀만 받기 |
| [PROCESS 오토파일럿] | ERPia 처리만 |
| [오토파일럿 중단] | 실행 중인 것을 멈춤 (실행 중에만 보입니다) |

- 단추 아래에 **남은 토큰** 이 보입니다. 실행할 때마다 토큰이 쓰입니다.
- "토큰이 없습니다" 가 나오면 실행되지 않습니다. 담당자에게 충전을 요청해 주세요.

## 6. 실행할 일과 시각 정하기 ([환경설정], 관리자)

왼쪽 메뉴의 **환경설정** 을 누릅니다. 관리자 계정에만 보입니다.

1. **실행 모듈**: 실행할 일을 켜고 끕니다. 다 고르셨으면 그 칸의 [적용] 을 누릅니다.
   - 하나 이상은 켜 두셔야 합니다.
2. **쇼핑몰 프리셋**: 주문을 받아 올 쇼핑몰을 켜고 끕니다. 그다음 [적용] 을 누릅니다.
   - 쇼핑몰 설정은 담당자가 해 드립니다.
3. **자동 실행**: 정해진 시각에 저절로 실행되게 합니다.
   1. [활성화] 를 켭니다.
   2. 요일(평일, 매일, 주말)을 고릅니다.
   3. [+ 시각] 을 눌러 실행할 시각을 넣습니다. 일정한 간격으로 되풀이하려면 [+ 반복 시간대] 를 누릅니다.
   4. 줄마다 '전체 모듈 실행' 또는 '선택 모듈만 실행' 을 고를 수 있습니다.
   5. 마지막에 [적용] 을 누릅니다.

> [적용] 을 누르지 않으면 바뀌지 않습니다. 그냥 나가려 하면 "적용하지 않은 변경이 있습니다" 하고 알려 드립니다.
> 시각을 더 넣을 수 없다고 나오면 ERPia 에 문의해 주세요.

## 7. 비밀번호 바꾸기

왼쪽 메뉴 **계정** → 현재 비밀번호, 새 비밀번호(8자 이상), 다시 입력 → [바꾸기]

## 8. 업데이트

새 버전은 **저절로** 설치됩니다. 누르실 것은 없습니다.
업데이트하는 동안 잠시 실행 단추가 잠기며, [오토파일럿] 화면의 버전 옆에 "업데이트됨" 이 보이면 끝난 것입니다.

## 이럴 땐 이렇게

| 이럴 때 | 이렇게 해 주세요 |
|---|---|
| '연결' 이 **끊김** 이에요 | PC 가 켜져 있고 윈도우에 로그인되어 있는지 봐 주세요. 그래도 끊김이면 시작 메뉴의 '오토파일럿 설정' 에서 [저장] 을 눌러 주세요. 그래도 안 되면 그 창 맨 위 줄 상태를 담당자에게 알려 주세요. |
| 결과가 **실패** 예요 | [기록] 탭에서 그 줄의 상세 정보를 담당자에게 알려 주세요. |
| ERPia 비밀번호를 바꿨어요 | '오토파일럿 설정' 창에서 새 비밀번호를 넣고 [저장] 을 눌러 주세요. |
| 자동 실행이 안 됐어요 | 그 시각에 PC 가 켜져 있고 로그인되어 있었는지, [환경설정] 에서 [활성화] 가 켜져 있는지 봐 주세요. |
| 휴대폰 인증이 필요한 쇼핑몰이에요 | 담당자가 휴대폰 앱 설정을 도와 드립니다. 실행 시각에 휴대폰을 켜 두세요. |

그 밖에 궁금하신 점은 언제든 담당자에게 편하게 물어봐 주세요.
