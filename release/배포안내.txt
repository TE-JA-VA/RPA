====================================================================
 ERPia RPA - 다른 PC 로 옮기는 방법
 (2026-09-14 기준)
====================================================================

■ 0. 설치 파일로 설치하기 (2026-09-29 부터 이 방법을 쓴다. 아래 1~9 는 손으로 옮기는 대비책)
    준비물 (관리자에게 받는다)
        업체코드, PC코드, 기계 계정 비밀번호  (대시보드 로그인 계정과 다르다)
        이 PC 의 ERPia 업체코드·아이디·비밀번호
        물류 모듈을 쓰면: 그 업체가 ERPia 에 등록한 택배사·박스·운임(구분) 이름, 운송장을 인쇄하는지 엑셀로 만드는지
    그 PC 에 미리 있어야 하는 것: 4번 (ERPia 설치, 'PC와 연결' + 휴대폰 연결, 프린터)
    RPA 를 돌릴 윈도우 계정은 관리자여야 한다. 그 계정으로 로그인해서 설치한다.

    1) AFTER_MARKET_RPA_Setup_<버전>.exe 를 그 PC 로 옮겨 실행한다.
       인터넷·메신저로 받은 파일이면 'Windows의 PC 보호' 가 뜬다 → [추가 정보] → [실행].
       (USB 로 옮기면 뜨지 않는다. 서명하지 않은 우리 프로그램이라 뜨는 것이다)
    2) 관리자 권한 요청에 [예] → [설치].
    3) 설치 끝 무렵 'AFTER MARKET RPA 설정' 창이 뜬다. 칸을 채우고 [저장].
       - 저장할 때 기계 계정으로 실제로 로그인해 본다. 틀리면 저장 단추 옆에 빨간 글씨로 까닭이 나온다.
       - 물류 모듈을 쓰면 '물류 처리 옵션' 칸을 채운다. 택배사·박스·운임은 ERPia 물류관리 > 배송정보설정 목록의
         글자 그대로 적는다 (다르면 물류관리에서 저장하지 못하고 멈춘다). 출력 방식은 수동(엑셀 파일)이 기본이고,
         자동(운송장 인쇄)이면 프린터를 고른다.
       - 예전에 압축 폴더로 쓰던 PC 면 [기존 설정값 가져오기] 로 옛 배포 폴더를 고른다.
         옛 에이전트 창이 켜져 있으면 닫으라고 한다. 저장 뒤 옛 폴더 이름을 '_옮김' 으로 바꿀지 묻는다 (예).
    4) 대시보드(https://rpa-test-f02e0.web.app)에서 이 PC 가 '연결' 로 보이고, 현황·기록 탭 오른쪽에
       '버전 …' 이 보이면 된 것이다.

    설치한 뒤
        - 에이전트는 윈도우에 로그인할 때마다 창 없이 켜진다. 오류로 죽으면 잠시 뒤 저절로 다시 켜진다.
        - 이 PC 는 늘 로그인된 상태로 둔다 (로그아웃·화면 잠금이면 RPA 가 ERPia 를 다룰 수 없다).
        - 설정을 바꿀 때: 시작 메뉴 → AFTER MARKET RPA → 'RPA 설정' (관리자 권한 요청이 뜬다).
          비밀번호 칸은 바꿀 때만 넣는다 (비우면 그대로).
        - 대시보드에 '연결 끊김' 이 계속 보이면 'RPA 설정' 을 연다. 기계 계정 비밀번호가 바뀌었으면
          새 비밀번호를 넣고 저장하면 에이전트가 다시 켜진다.
        - 설치 자리: 프로그램 C:\Program Files\AFTER MARKET\RPA
                     설정·기록 C:\ProgramData\AFTER MARKET\RPA (관리자만 열린다)
          기록(에이전트_기록.txt, *_result.txt 등)은 그 data 폴더에 있다.
        - 지우기: 설정 → 앱 → 'AFTER MARKET RPA' 제거. 설정·기록도 지울지 묻는다 (다시 설치할 거면 아니요).
        - 새 버전: 새 설치 파일을 그대로 실행하면 덮어 설치한다 (설정은 그대로). RPA 가 도는 중이면 끝난 뒤 하라고 한다.


■ 실행 순서
    Run_All.bat  하나만 관리자 권한으로 실행하면 된다.
      0) RPA_Dashboard.exe : 진행 현황 대시보드를 작은 창으로 띄운다 (이미 떠 있으면 그대로 둔다)
      1) Prepare_RPA.exe : 메일에서 '>>>' 로 시작하는 건의 첨부파일을
                           바탕화면\ERPIA_AI\ERPIA_AI_EXCEL 로 내려받는다.
      2) ERPia_RPA.exe   : ERPia 를 돌린다. 위에서 받은 엑셀을
                           주문매핑 매출처리 단계에서 업로드한다.


■ 1. 프로그램 폴더 - 통째로 복사해 간다
    (이름과 위치는 자유. 아래 파일들이 한 폴더에만 모여 있으면 된다)

        Run_All.bat                프리페어 -> 루틴 순서로 실행
        Prepare_RPA.exe            프리페어 RPA
        ERPia_RPA.exe              루틴 RPA
        RPA_Dashboard.exe          현황 대시보드 (웹, 아래 8번)
        RPA_UserConfig.json        사용자 설정 한 파일 (ERPia 로그인 · 물류 · 실행 모듈 · 프리페어 사이트 · ERPia 위치)
        manifest.json              버전 번호와 프로그램 파일 목록 (지우지 말 것)
        (브라우저는 그 PC 에 깔린 Microsoft Edge 를 쓴다 - 아래 2번)

    ※ *_result.txt, *_log.txt 는 실행하면 생기는 기록이라 가져갈 필요 없다.


■ 2. 브라우저 - 그 PC 에 깔린 Microsoft Edge (2026-10-06 부터)
    프리페어 RPA 와 옵저버는 윈도우에 기본으로 깔린 Edge 를 빈 프로필로 띄운다. 따로 옮길 것이 없다.
    그 PC 사용자가 쓰는 Edge 의 로그인·쿠키와는 섞이지 않는다.
    (그 전 판은 ms-playwright 폴더(약 715MB)를 exe 옆에 두었다. 새 판을 설치하면 그 폴더는 지운다)

    Edge 를 지운 PC 면 "Microsoft Edge 가 없습니다" 로 멈춘다 → Edge 를 설치한다.
    확인: Prepare_Observer.exe --check 에 '브라우저: Microsoft Edge <버전>' 줄이 나오면 된다.

    ERPia_RPA.exe 는 브라우저를 쓰지 않는다.


■ 3. 작업 폴더 - 바탕화면\ERPIA_AI
    프로그램이 쓰는 파일은 전부 여기 모인다. 없으면 알아서 만든다.

        바탕화면\ERPIA_AI\
          ERPIA_AI_EXCEL\       프리페어가 받아 루틴이 업로드 (자동 생성)
          ERPIA_AI_JOBS\        운송장 출력 결과 (자동 생성)
          RPA_STATUS\           대시보드용 진행 기록 (자동 생성)
          AI 로그인 실패(...).txt  로그인 실패 기록 (생기면)

    여기에 사람이 넣을 것은 없다. 모두 실행하면서 자동으로 만들어진다.
    설정은 1번 프로그램 폴더의 RPA_UserConfig.json 하나다.

    ※ 예전의 ERPIA_AI.txt(바탕화면)와 WebManageConfig.json 은 이제 쓰지 않는다.
      그 두 파일만 있는 PC 는 에이전트가 처음 켤 때 RPA_UserConfig.json 으로 합치고
      옛 파일은 .old 로 이름을 바꾼다. .old 에는 평문 비밀번호가 있으니 확인 뒤 지운다.


■ 4. 그 PC 에 미리 있어야 하는 것
    (1) ERPia 프로그램 설치
        ERPia 위치는 RPA_UserConfig.json 의 ERPia.ExePath 다.
        지금 값: C:/Program Files (x86)/OneZeroSoft/ERPiaNet/ERPiaMain.exe
        틀리면 설치 기록과 기본 설치 폴더에서 찾아 고쳐 적는다. 그래도 없으면
        에이전트를 켤 때(또는 루틴을 직접 실행할 때) ERPiaMain.exe 를 고르는 창이 뜬다.

    (2) 'PC와 연결'(Phone Link) 설치 + 휴대폰 연결
        2차인증 문자를 PC 에서 읽어야 하므로 반드시 필요하다.
        휴대폰과 블루투스로 연결되어 '연결됨' 상태여야 한다.

    (3) 프린터
        RPA_UserConfig.json 의 Logistic.Printer 값과 같은 이름의 프린터가 있어야 한다.
        같은 Logistic 의 cboTag(택배사)·cboTagAmt(박스)·cboBeasong_Gu_Apply(운임)는 빈 틀에서 비어 있다 -
        그 업체가 ERPia 배송정보설정에 등록한 글자 그대로 적는다. cboBS_Auto_YN 은 N 수동(엑셀) / Y 자동(인쇄).


■ 5. 실행 전 점검 (권장)
    관리자 권한 명령 프롬프트에서:
        Prepare_RPA.exe --check
        ERPia_RPA.exe --check
    둘 다 '정상' 이 나오면 Run_All.bat 을 실행한다.


■ 6. 실행 중 지켜야 할 것
    - 반드시 관리자 권한으로 실행 (ERPia 가 관리자 권한으로 돌기 때문)
    - PC 화면을 잠그지 말 것
        화면을 읽어서 조작하는 방식이라, 잠기면 ERPia 조작도 안 되고
        Phone Link 도 갱신이 멈춰 인증번호 문자를 못 받는다.
    - 휴대폰을 PC 근처에 두고 연결을 유지할 것
    - 1PC 1프로그램 원칙 (ERPia 를 두 개 띄우지 말 것)


■ 7. 문제가 생기면 - 로그 보는 법
    로그는 전부 exe 와 같은 폴더에 생긴다. 한 줄씩 바로 기록되므로
    중간에 강제 종료해도 거기까지는 남는다.

          prepare_result.txt      프리페어 RPA (로그인 / 2차인증 / 메일)
          run_routine_result.txt  루틴 RPA (ERPia 전 과정)
          sms_watch_log.txt       문자 읽기 점검 기록
          shots\                  실패한 화면 사진 (생기면)

    두 result 파일은 실행할 때마다 새로 쓴다. 남겨야 하면 먼저 복사할 것.

    자주 보게 되는 줄:
      '내림차순 확정 (맨 위 '정상')'      상품상태 정렬이 제대로 된 것
      '경계 발견 (위로 N페이지)'          보류할 비정상 구간의 시작을 찾은 것
      '대기 N초 (대화 N건, 새 문자 없음)' 인증문자를 기다리는 중
      '문자를 받지 못했습니다'            뒤에 그때 보이던 문자 목록이 따라온다


■ 8. 현황 대시보드 - 진행 상황을 브라우저로 보기
    Run_All.bat 을 실행하면 RPA_Dashboard.exe 가 작은 창으로 함께 뜬다.
    (이미 떠 있으면 새로 띄우지 않는다. 그 창을 닫으면 대시보드만 꺼지고 RPA 는 계속 돈다)

    보는 주소
      이 PC           http://localhost:8765
      사내 PC/휴대폰  http://<이 PC 의 IP>:8765
                      실제 주소는 대시보드 창에 찍혀 나온다. 같은 사내망(와이파이)이어야 한다.

    로그인 (화면을 열면 업체코드 / 아이디 / 비밀번호를 묻는다. 업체코드는 확인하지 않고 표시에만 쓴다)
      관리자      admin / admin   현황·이력 보기 + 실행(전체/프리페어/루틴) + 자동 실행 설정 + ERPia 종료
      일반 사용자 user  / user    현황·이력 보기
      - 기본 비밀번호는 환경설정 > 계정에서 꼭 바꿀 것. 바꾸면 다른 기기의 그 계정 로그인은 풀린다.
      - 비밀번호를 잊었으면 RPA_STATUS\settings.json 의 "accounts" 부분을 지우고 대시보드를 다시 띄운다
        (기본 계정으로 돌아간다). 비밀번호는 해시로만 저장되어 파일에서 읽을 수 없다.
      - 대시보드를 다시 띄우면 모두 다시 로그인한다. 12시간 안 쓰면 자동으로 풀린다.

    화면
      현황  지금 도는 프로그램, 몇 번째 단계인지, 처리 건수, 경과 시간, 최근 로그.
            관리자에게는 맨 위 카드에 '전체 실행'(Run_All.bat = 프리페어 -> 루틴), 각 프로그램 카드 제목 줄에
            '프리페어 실행'(Prepare_RPA.exe 만) / '루틴 실행'(ERPia_RPA.exe 만) 버튼이 있다. 어느 하나가 도는 동안은 셋 다 잠긴다.
            중단되거나 비정상 종료되면 사유가 함께 뜬다.
      이력  지난 실행 목록 (프로그램/기간으로 거르기). 한 줄을 누르면 단계와 로그가 펼쳐진다.

    방화벽
      다른 PC/휴대폰에서 보려면 8765 포트가 열려 있어야 한다.
      Run_All.bat 이 처음 한 번 'ERPIA_RPA_Dashboard' 규칙을 만든다
      (개인/도메인 네트워크만 연다. 공용 네트워크에는 열지 않는다).
      규칙을 지우려면 관리자 명령 프롬프트에서:
        netsh advfirewall firewall delete rule name="ERPIA_RPA_Dashboard"

    환경설정 (세 번째 탭)
      자동 실행  [관리자] 켜면 정한 요일·시간에 Run_All.bat (프리페어 -> 루틴) 을 띄운다.
                 - 요일은 매일/평일/주말 또는 하나씩 고르고, 시간은 5분 단위로 하루 3개까지 넣을 수 있다.
                 - 수동 실행은 예약 시각을 바꾸지 않는다. 대시보드를 다시 켜면 꺼져 있던 동안 지난 예약은 건너뛴다.
                 - 대시보드 창이 떠 있는 동안만 돈다. 창을 닫으면 자동 실행도 멈춘다.
                 - 앞 실행이 아직 돌고 있으면 끝날 때까지 기다렸다가 띄운다 (건너뛰지 않는다).
                 - 값을 바꾸면 '적용' 을 눌러야 저장된다. 안 누르면 빨간 경고가 계속 뜬다.
                 - 현황 맨 위 카드에 '다음 자동 실행' 과 '마지막 실행 (자동/수동)' 이 나온다.
                 - 일반 사용자는 값을 볼 수만 있다.
      계정       로그아웃 (이 브라우저의 대시보드 로그인만 끝낸다), 비밀번호 바꾸기. 모든 계정.
      ERPia      [관리자] ERPia 종료 (ERPia 는 종료가 곧 로그아웃). RPA 가 도는 중에는 눌리지 않는다.
      화면       강조색 (버튼·스위치), 밝은/어두운 화면. 보는 기기에만 저장된다.
                 프리페어·루틴을 구분하는 프로그램 색은 현황 카드 제목 앞의 색 표시를 누르면 고를 수 있다
                 (Solarized 8색, 두 프로그램은 서로 다른 색이어야 한다).
      권한       지금 실행·자동 실행·ERPia 종료는 ERPia(관리자 권한) 를 다루므로, Run_All.bat 을
                 관리자 권한으로 실행해 대시보드를 띄워야 한다. 아니면 환경설정 화면에 노란 경고가 뜬다.
      설정 파일  바탕화면\ERPIA_AI\RPA_STATUS\settings.json (자동 실행 값과 계정 해시)

    알아둘 것
      - RPA 를 조작하는 기능은 관리자의 세 가지(지금 실행, 자동 실행, ERPia 종료)뿐이다. 진행 중인 RPA 를 멈추는 기능은 없다.
      - 사내망 안에서는 HTTP 라 비밀번호가 평문으로 지나간다. 사내망 밖에 열지 말 것. 오른쪽 위에는 로그인한 업체코드·아이디와 권한이 나온다.
      - '비정상 보류' 건수는 행을 하나씩 세지 않고 화면 쪽수로 추정한 값이다 ('약' 이 붙는다).
      - '상단/하단 선택' 건수는 화면에 보이는 행 기준이다.
      - 기록은 바탕화면\ERPIA_AI\RPA_STATUS 에 쌓인다. 지워도 RPA 동작에는 영향이 없다.
      - 포트를 바꾸려면 Run_All.bat 의 DASHBOARD_PORT 값을 고친다.
      - 회사 보안 프로그램(SentinelOne 등)이 RPA_Dashboard.exe 를 지울 수 있다.
        그러면 대시보드만 뜨지 않고 RPA 는 그대로 돈다 (Run_All.bat 이 안내만 하고 넘어간다).
        대시보드를 쓰려면 IT 담당자에게 이 exe 의 허용(예외 등록)을 요청할 것.


■ 9. 주의
    RPA_UserConfig.json 에 ERPia·웹사이트 비밀번호가 들어 있다.
    에이전트가 처음 켤 때 이 PC·이 윈도우 계정에서만 풀리게 잠근다("dpapi:...").
    잠기기 전(평문) 파일과 .old 파일은 외부로 나가지 않게 관리하고, 쓰임이 끝나면 지울 것.
    비밀번호를 바꿀 때는 PW 칸에 평문으로 적고 에이전트를 다시 띄운다.
